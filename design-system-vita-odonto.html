CSS — ANIMAÇÃO COMPLETA DO BOTÃO
/* ── BOTÃO VITA ODONTO: ONDA DE LUZ (SHIMMER) & ZOOM SUAVE ── */

/* 1. Estrutura do Botão CTA */
.btn-cta-vita {
  position: relative;
  overflow: hidden;        /* Garante que o brilho não vaze nem altere o tamanho */
  isolation: isolate;
  background: #E8A33D;       /* Cor solar de conversão */
  color: #0A1517;
  font-family: 'Poppins', sans-serif;
  font-size: 12px;
  font-weight: 700;
  letter-spacing: 0.06em;
  text-transform: uppercase;
  padding: 12px 28px;
  border-radius: 9999px;
  border: none;
  cursor: pointer;
  box-shadow: 0 4px 16px rgba(232, 163, 61, 0.30);

  /* Animação sutil de Zoom Suave (Scale Up) */
  transition: transform 0.35s cubic-bezier(0.2, 0.8, 0.2, 1),
              box-shadow 0.35s ease,
              background 0.2s ease;
}

/* 2. Efeito de Zoom Suave no Hover / Click */
.btn-cta-vita:hover {
  transform: scale(1.04);   /* Zoom suave e elegante */
  background: #F2B455;
  box-shadow: 0 8px 24px rgba(232, 163, 61, 0.45);
}
.btn-cta-vita:active {
  transform: scale(0.985);  /* Micro clique táctil */
}

/* 3. Onda de Luz Suave Contínua (Shimmer Wave: esquerda -> direita) */
.btn-cta-vita::after {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  width: 70%;
  height: 100%;
  background: linear-gradient(
    90deg,
    rgba(255, 255, 255, 0) 0%,
    rgba(255, 255, 255, 0.15) 30%,
    rgba(255, 255, 255, 0.60) 50%,
    rgba(255, 255, 255, 0.15) 70%,
    rgba(255, 255, 255, 0) 100%
  );
  transform: translateX(-160%) skewX(-25deg);
  animation: shimmerSweep 3.2s cubic-bezier(0.4, 0, 0.2, 1) infinite;
  pointer-events: none;
  z-index: 2;
}

/* 4. Keyframe da Onda Contínua em Loop */
@keyframes shimmerSweep {
  0% {
    transform: translateX(-160%) skewX(-25deg);
    opacity: 0;
  }
  10% {
    opacity: 1;
  }
  45% {
    transform: translateX(260%) skewX(-25deg);
    opacity: 1;
  }
  100% {
    transform: translateX(260%) skewX(-25deg);
    opacity: 0;
  }
}

// Como Aplicar na Landing Page da Vita Odonto
01
Importar Poppins
Adicione a fonte Poppins via Google Fonts (pesos 300, 400, 500, 600 e 700) para um visual moderno, acolhedor e humanizado.
02
Copiar Tokens CSS
Cole o bloco :root { ... } no arquivo CSS principal. Todas as cores, tipografia e tamanhos estarão sincronizados.
03
Ativar Shimmer Wave no CTA
Adicione a classe .btn-cta-vita ao botão de conversão. A onda de luz atravessa continuamente em loop sem deformar o botão.
04
Zoom Suave (Scale Up)
O efeito de zoom com transform: scale(1.04) e curva cubic-bezier proporciona uma sensação táctil premium e altamente convidativa.
